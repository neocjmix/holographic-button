# Contributing

Issues and focused pull requests are welcome. Please keep the rendered WebGL silhouette, reflective rim, and DOM hit area geometrically aligned.

1. Install dependencies with `npm ci` at the repository root.
2. Run `npm run check` for the complete test, typecheck, build and packaging checks.
3. Describe visual or browser-specific changes clearly and include the tested browser/device.
